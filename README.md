# 우리 아이 그림책 만들기

아이가 그린 그림과 사진으로 그림책을 만들고, 인쇄소에 보낼 PDF까지 만들어 주는 웹 앱입니다.
설치할 것도, 가입할 것도 없습니다.

> **아이 사진과 그림은 이 컴퓨터 밖으로 나가지 않습니다.**
> 모든 작업은 지금 쓰고 있는 브라우저 안에서만 이뤄지고, 서버로 올라가는 것은 하나도 없어요.

## 이렇게 쓰세요

PC의 **Chrome 또는 Edge**에서 가장 잘 동작합니다.

### 1. 그림 사진 찍기

- 밝은 곳에서 찍어 주세요. 창가의 낮 시간이 좋아요.
- 그림자가 지지 않게 하세요. 찍는 사람 몸이나 휴대폰이 종이에 그림자를 드리우지 않도록 조심해 주세요.
- 종이 전체가 화면에 나오게 찍어 주세요. 네 모서리가 모두 보여야 반듯하게 펴 줄 수 있어요.
- **아이폰 사진(HEIC)은 JPG로 바꿔서** 넣어 주세요. 아이폰 설정의 카메라 > 포맷 > "호환성 우선"으로 찍거나, 변환 앱을 쓰면 됩니다.

### 2. 책 만들기

1. [새 책 만들기]를 누르고 책 제목, 아이 이름, 책 크기를 정합니다.
2. 왼쪽에서 앞표지, 뒤표지, 내지를 고르고 [+ 쪽 추가]로 쪽을 늘립니다.
3. [배경 사진 넣기]로 사진을 깔고, [글자 넣기]로 이야기를 적어요.
4. 책 크기는 쪽을 만들기 전에만 바꿀 수 있어요.

### 3. 그림 정리하기

[그림 넣기]를 누르면 3단계로 그림을 깔끔하게 만들어 줍니다.

1. 종이의 네 모서리를 맞춥니다.
2. 종이 바탕을 지웁니다.
3. 남은 얼룩을 지우개로 다듬습니다.

정리된 그림은 쪽 위에서 끌어서 옮기고, 모서리를 당겨서 크기를 바꿀 수 있어요. [손글씨 넣기]도 같은 방법이에요.

### 4. 저장하고 백업하기

- 작업 내용은 **이 브라우저 안에 자동으로 저장**됩니다. 다른 컴퓨터나 다른 브라우저에서는 보이지 않아요.
- 브라우저 방문 기록·사이트 데이터를 지우면 책도 함께 사라질 수 있어요.
- 그러니 중요한 책은 책 목록에서 **[책 파일로 저장]**을 눌러 `.kidbook` 파일로 따로 보관해 두세요.
  다른 컴퓨터에서는 [책 파일 불러오기]로 다시 열 수 있습니다.

### 5. 인쇄 업체에 PDF 보내기

1. 책을 연 뒤 위쪽의 [PDF 만들기]를 누릅니다.
2. 안내 문구(배경 사진이 없는 쪽, 흐릿할 수 있는 사진 등)를 확인합니다.
3. PDF 두 개가 만들어져요. **표지 PDF**와 **내지 PDF**입니다. 둘 다 내려받아 인쇄 업체에 보내 주세요.
4. 재단용 여백(3mm)이 포함되어 있습니다.

## 개발자용

```bash
npm install          # 의존성 설치
npm run dev          # 개발 서버
npm test             # 단위 테스트 (Vitest)
npm run build        # 타입 검사 + 빌드 (dist/)
npx playwright install chromium   # 최초 1회
npm run e2e          # E2E 스모크 테스트 (빌드 후 vite preview로 실행)
npm run fixtures     # e2e/fixtures 사진 파일 다시 만들기
```

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트와 빌드를 거쳐 GitHub Pages에 배포합니다.
